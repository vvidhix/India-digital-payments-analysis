# India-digital-payments-analysis/ RBI data 2019- 2025 
Overview
Analysis of India's digital payment ecosystem using Reserve Bank of India 
monthly payment systems data spanning 2019 to 2025.

 Data Source
Reserve Bank of India — Database on Indian Economy (DBIE)
Sourced via Kaggle | 73 months of data

Tools Used
- SQL (MySQL) — data analysis and querying
- Notion — project documentation and findings with powerbi dashboards. 

 Key Findings
1. October consistently peaks in UPI volume — Diwali festive season effect
2. India processes ₹12.8 lakh crores via UPI monthly on average
3. ATM cash withdrawals remain persistently high despite UPI growth
4. NEFT dominates transaction VALUE while UPI dominates transaction VOLUME
5. 34 of 73 months exceeded average UPI value — all from 2023 onwards
